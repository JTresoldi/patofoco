# 🦆 Patofoco App

O **Patofoco** é um aplicativo de Pomodoro desenvolvido em React, criado para ajudar no foco, organização do tempo e gerenciamento de pausas de forma simples, visual e divertida.

A ideia do projeto é unir produtividade com uma identidade visual leve, usando o mascote **Patofoco**, um patinho fofo que acompanha o usuário durante os ciclos de foco e descanso.

## 🚀 Tecnologias utilizadas

* React
* Vite
* Tailwind CSS
* React Router
* React Icons
* React Circular Progressbar

## 🎯 Funcionalidades

* Timer Pomodoro
* Modo foco
* Pausa curta
* Pausa longa
* Botão de iniciar e pausar
* Botão de reiniciar o tempo
* Interface responsiva
* Layout com sidebar e topbar
* Indicador visual circular do tempo
* Mascote personalizado do Patofoco

## ⏱️ Modos do timer

| Modo        | Tempo      |
| ----------- | ---------- |
| Pomodoro    | 25 minutos |
| Pausa curta | 5 minutos  |
| Pausa longa | 15 minutos |

## 📦 Como instalar o projeto

Clone este repositório:

```bash
git clone https://github.com/JTresoldi/patofoco.git
```

Entre na pasta do projeto:

```bash
cd patofoco
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse no navegador:

```bash
http://localhost:5173
```

## 🧠 Objetivo do projeto

O objetivo do Patofoco é praticar conceitos importantes do React, como:

* Componentização
* Estados com `useState`
* Efeitos com `useEffect`
* Props entre componentes
* Controle de tempo com `setInterval`
* Organização de layout com Tailwind CSS
* Criação de uma interface amigável e reutilizável
